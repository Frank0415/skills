# 中文教学文字修订

当讲义出现模板腔、重复铺陈或难以理解的解释时，使用本参考修订相关段落。目标是让学生读懂课件中的概念和推理。篇幅由教学内容决定，不按字数、句数或风格评分扩写、删减。

## 保留教学内容

- 保留来源中的事实、条件、数值、公式、术语和必要推导。风格修订不改变 `cslides` 的逐页翻译与完整讲解要求。
- 保留影响结论的真实不确定性和适用范围；删除重复的软化措辞。
- 区分课件原意、合理解读和上下文补足。补充具体例子时，使用可以验证的数值与推理，并标明它是教学补充。
- 沿用同一个概念的名称，不为了词汇变化轮换近义词。

## 用具体解释替换模板腔

| 问题 | 修订方向 |
|---|---|
| “具有重要意义”“发挥关键作用” | 说明它解决什么问题、影响哪个量或使哪一步成立。没有新增信息时删除。 |
| “深入探讨”“全面展示”“值得注意的是” | 直接写后面的事实或推理。 |
| “专家认为”“研究表明”却无具体来源 | 回到课件证据或可核实的来源；没有依据时不保留归因。 |
| “不仅是……更是……”等修辞对比 | 直接说明关系；保留真正影响理解的概念对比。 |
| 每段都以泛泛总结收尾 | 删除重复结论；需要过渡时，说明下一步依赖什么。 |
| 只有公式结果或名词清单 | 补上变量、条件和必要中间步骤，而不是增加评价性形容词。 |
| “或许有可能在某些情况下” | 明确实际条件；信息不足时保留一个准确的不确定表述。 |

## 按论证组织段落

让每段解释一个具体问题，并把依据或推理放在结论附近。按材料需要使用自然长短句，不为改变节奏拆散一个条件或推导。

比较、顺序步骤和并列条件可以用表格或列表；跨页机制和推导用连贯叙述串起来。三项内容本身不是问题，不为回避“三段式”删项、凑项或改变模板结构。

保留有用的标题、强调和连接词。删去的是装饰性重复，不是导航、技术层次或因果关系。写作建议不修改模板的 CSS、组件和信息架构。

讲义使用与课程匹配的说明语气。无需增加个人感受、幽默、作者经历、题外话或对学生的赞美来制造“人味”。必要背景应服务于当前概念，并按 `cslides` 的规则标注。

## 示例

原文：

> 值得注意的是，这不仅仅是一次矩阵变换，更是深刻揭示了正交矩阵的重要作用，确保了计算结果的可靠性。

若本段实际在解释正交变换保持长度，可改为：

> 因为 QᵀQ = I，所以 ‖Qx‖² = xᵀQᵀQx = xᵀx = ‖x‖²。因此，乘以 Q 不改变向量的欧氏长度。

这段改写只主张等式能够证明的性质，不把长度保持扩展为未经证明的“计算可靠”。实际写入 HTML 时，按 `cslides` 的数学渲染规则标记这些公式。

## 结束修订

确认相关段落保留了原有教学信息、解释了必要的推理，并去掉了重复和空话后结束。交付仍使用 `cslides` 的输出格式，不额外附上人性化评分、风格检查表或改写说明，除非用户要求。
